Bolton Timber Supplies: built from Figma with AI

A UK timber merchant's design moved from Figma into Webflow by Claude, with the design system and animations included.

Webflow

The problem

Rebuilding a Figma design in Webflow by hand is slow. Every color, font size and animation has to be set up again.

How it works

Figma design→Claude reads it→Design system as variables→Pages built via MCP→Animations→I refine→Live site

What Claude handled

  • The full design system (colors, type and spacing) set up as Webflow variables.
  • Every page built directly in Webflow through the Webflow MCP.
  • Animations carried over from the design.
  • Clean, consistent class names so the site stays easy to edit.

What I handled

Small spacing fixes and the responsive details that make the site work well on every screen.

The result

The build took about an hour instead of four, with no more than 30 minutes of my time. I now use this process on client builds at a design agency.
