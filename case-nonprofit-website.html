Donation website for a nonprofit

A Webflow site that guides every visitor to the right way to give.

Service
Webflow + Automation
Industry
Nonprofit
Built with
Webflow, Claude, Fundraise Up, Klaviyo
View live site ↗

The problem

The old site had no clear path to giving. People who wanted to donate had to find their own way.

What I built

  • Set up Fundraise Up as the donation platform, built into the site.
  • A fully responsive Webflow site with clear donate buttons on every page.
  • Project and campaign pages people can filter, using Finsweet CMS Filter.
  • Swiper.js sliders to feature live campaigns.
  • New pages and components added as each campaign launches.

Where AI helped

I built the site with Claude working directly in Webflow through the Webflow MCP. That made new pages and components faster to build and keep consistent.

The automation layer

Leads
Website form→Klaviyo
Donors
New donation→Webhook→Zapier→Klaviyo

The result

  • Smoother donor flow, from landing to donation.
  • Easy navigation with clear, simple calls to action.
  • A fast-loading site on every device.
  • Every lead and donor lands in Klaviyo automatically.
