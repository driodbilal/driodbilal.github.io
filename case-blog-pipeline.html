A keyword goes in. A researched, checked and illustrated WordPress draft comes out, ready for one human review.

The problem

Every blog took about two hours of research, writing, image work and back-and-forth before it could go live.

How it works

Keyword sheet→Research→AI draft→Quality check→Images→Google Doc + ClickUp→Editor approves→WordPress draft

Where AI does the work

  • Researches real product details from the brand's site, plus stats from the web.
  • Writes to SEO rules: short slug, meta description under 150 characters, clean headings.
  • Checks its own draft and rewrites it, up to three times, before a person sees it.
  • Creates the hero image and adds real product photos inside the post.
  • Editors ask for changes in a ClickUp comment and the draft rewrites itself.

Human in the loop

Nothing publishes on its own. Every post lands as a WordPress draft and a person clicks publish.

We kept improving it

I built a second version as a Claude Code agent and tested it side by side with the n8n pipeline on the same keywords. The agent wrote stronger drafts, and its first post is now with the team for review.
